# G06 齐套闸（Readiness Gate）

[11] 本闸：[10] 资产生产后、[12] 锁镜前。**人审 + 脚本覆盖率**合为一道闸。
覆盖率：`python validation/coverage.py <root>`（等价 G06）。

## 机器可查
- BOM 每条硬需求是否有文件落在 target_path
- 状态是否为 approved（produced 未审不算齐）
- **覆盖率 = approved / 硬需求总数，必须 100%**；清单列出每一件缺/待审
- 尾帧链父镜：将被消费的父尾帧目标路径是否就位（内容随父镜生成）
- 开口角色：voice 与 **tts wav** 是否各有一件（只核存在，**不核时长**）

## 人审（逐 member，通过权在用户）
1. **逐 member 开图目视**，不是看文件名：整张内容是否＝资产设计卡；
   人物 sheet 四格是同一人、中性表情、饰品在身；道具/场景宫格各格是同一物、
   同一空间；single 单图与设计卡一致。
2. **每镜绑定的 cell 是否与该机位视点一致**：多镜可共一格（含 single 单图），
   但格内视图须盖得住这些镜；道具所需视图在宫格内有对应格——这是历史漏料点。
3. 饰品/随身物穿戴形制是否对；场景宫格各格的陈设是否一致（single 单图同样核对）。
4. tts/voice：试听嗓音是否是该角色；内容随便烧即可，不要求贴合台词。
5. Soul 的画面条款：关键色彩、关键姿态、关键物象是否在资产中成立。
- 审件时须展示该件 used_in（用于哪些镜、什么保留方式）。

## 处置
- 资产做得不对（含任一 cell 废）→ **整张 member 退回 producer 重烧**，禁止补生单格、禁止手工拼贴。
- 发现是**设计漏派 / cell 缺失 / 状态缺资产** → 回分镜走 ECN（补 needs、重过 G05、重派 BOM），禁止用「只取质感」近图糊住。
- 100% 未达成前，不得锁镜、不得写提交词。
