# G03 剧本闸

审：`02-screenplay/screenplay.md`｜写手：[../crew/screenwriter.md](../crew/screenwriter.md)

## 开工前置（闸前先确认）
小说过 G01、**魂已确认**、**风格定向已冻结（G02）**、charter 已批（**目标模型已由 [2] 回写锁定**）。缺任一不进入。

## 风格符合（人审）
- 外化手法是否与风格定向一致（淡墨留白 vs 半绘半写光影）；出现该画风禁止项（如要求照片式皮肤/镜头景深语言）即打回。
- 是否写了画风承载不了的场面。

## 可逐项核对（人工执行，无脚本）
- 六步判断六块齐全（含结构重排/合并/砍枝节清单）
- 每场有场头（时地内外、估时）与 `目标｜阻碍｜转折`
- 台词按场内编号、可被引用
- 细腻对照表每行有小说引文（无引文＝无效行）
- 每个母题有 首次/变奏/回收 三镜（或已显式降级）
- 分集交付时有分集表

## 人审（薄稿否决，任一即退）
1. 对照表抽查：任取一行，30 秒内在小说定位原句；引文与剧本载体是否真对应。
2. 关键内心是否有外化载体；只删不补＝抽干；枝节全保＝注水。
3. 场是否真有戏：无目标/阻碍、场末无变化＝过场冒充。
4. 关键节拍有无主动作，还是整场对白墙。
5. 遮名读台词：听得出谁在说吗？是否说明文复述。
6. 结构大改有无「原位→新位」说明；是否偷改了因果方向/人物结局。
7. ⚠ 风险段是否照写未被擅自软化。
8. 旁白是否经特批；批前出现＝越权。

## 缺陷处置
| 缺陷 | 改法 |
|---|---|
| 抽干（砍内心无载体） | 补物件/微动作/环境/言行矛盾载体 |
| 注水（载体过不了三问） | 删装饰性载体 |
| 对照无引文/对不上 | 回小说定位原句，重写该行 |
| 场无戏 | 立 目标/阻碍/转折，或删场 |
| 声口混同 | 以声口锚为原土分写 |
| 偷改因果/结局 | 回退，改走结构重排说明并报审 |
| 因果洞/时间线错 | 进待决疑点，停在裁决前 |
